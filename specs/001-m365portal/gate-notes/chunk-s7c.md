Initial JS = module entry plus every `modulepreload` chunk named in `index.html`, gzip level 9; entry CSS = inline `<style>` blocks plus linked stylesheets, raw; first load = Brotli q11 of HTML + linked CSS + initial JS, plus the preloaded font as shipped. - The ratchet needs a base ref. The script uses `--base-ref`, `BUNDLE_BUDGET_BASE_REF` or `origin/$GITHUB_BASE_REF` (set on pull requests by GitHub), fetches that single commit when the checkout is shallow, and says plainly when it skipped the check. `ci.yml` was not edited (s7a's file), so the `Bundle budget` step relies on `GITHUB_BASE_REF` and the script's own `git fetch --depth=1 origin <base>`; contents:read is enough for that fetch. On push to main there is no base, so only the absolute budget runs.
