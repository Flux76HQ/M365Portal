## 4. Frozen interfaces (contract C12, G3)

The component inventory, with every prop, is in `chunk-s3b.md` section 7 (26 primitives, `MotionProvider`) and the utility vocabulary in section 6; both are unchanged. New in this chunk, `apps/web/src/components/data-table/` (import from `DataTable.tsx`, which re-exports the types):

| Export | Shape |
|---|---|
| `DataTable<Row>` | `id`* (table id), `labels`* (`DataTableLabels`), `columns`* (`DataTableColumn<Row>[]`), `rows`* (the current page), `totalCount`*, `status`* (`loading`, `ready`, `error`), `getRowId`*, `getRowLabel`*, `search`* and `onSearchChange`* (`DataTableSearch`), `defaultSort` (`name`, `-name`), `defaultPageSize` (25 if offered), `pageSizeOptions` (10, 25, 50, 100), `searchable` (true), `filters` (`{ key, label, allLabel, options }[]`), `onRetry`, `requestId`, `emptyAction`, `stateHeadingLevel` (3), `bulkActions` (`{ id, label, destructive?, onSelect(selection) }[]`), `rowActions(row)` (`{ id, label, destructive?, disabled? }[]`), `onRowAction(actionId, row)`, `details` (`{ title(row), description?(row), render(row) }`), `columnStorage`, `className` |
| `DataTableColumn<Row>` | `id`*, `header`* (translated), `cell(row)`*, `sortable`, `hideable` (true), `hiddenByDefault`, `align` (declared, not yet used for layout) |
| `DataTableSearch` | `{ q?, sort?, page?, size? } & { 'f.<key>'?: string }`; values are strings (numbers accepted for `page` and `size`); the page validates it with its router and hands it in; a change leaves through `onSearchChange(next)` as a complete search without default values |
| `DataTableLabels` | typed object of 43 fields (14 of them functions) (strings and `(values) => string` functions), `labels.tsx`; no field is optional, so a missing translation is a compile error |
| `DataTableColumnStorage` | `read(tableId): DataTableColumnPrefs | null`, `write(tableId, prefs)`, `clear(tableId)`; `DataTableColumnPrefs = { hidden: string[]; order: string[] }`; synchronous, must not throw |
| `DataTableSelection` | `{ scope: 'page'; ids; total }` or `{ scope: 'all'; total; query }` (the search without the page) |
| helpers | `readQuery`, `writeSearch`, `queryKey`, `nextSort`, `hasActiveFilters` (query-state.tsx, pure); `reconcilePrefs`, `moveColumn`, `defaultPrefs` (column-picker.tsx) |

Dependency added through the install protocol: `@tanstack/react-table@9.2.8` (dependencies of `@m365portal/web`; pulls `@tanstack/react-store` and `@tanstack/table-core`). Comments of `pnpm-workspace.yaml` were put back after `pnpm add`; the lockfile only gained lines.
