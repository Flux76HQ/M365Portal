# ADR-0031: Schema snapshots keyed by schema version, taken from the migrated database (PD-05)

Samenvatting (NL): Schema-snapshots per schemaversie, gemaakt van de gemigreerde database.

## Status

Plan

Source: plan section 6.2, row PD-05.

## Context

`drizzle-kit export` renders the TypeScript schema, which lacks the hand-written audit triggers. A snapshot per application version would be identical for most releases.

## Decision

Snapshots are `apps/server/schema-snapshots/<NNNN>-<tag>.sql`, keyed by the migration index and generated by applying the shipped migrations to an empty database and dumping `sqlite_master` in a fixed order. A parity test compares that database with one built from `drizzle-kit export` (triggers excluded). This is our reading of baseline section 2 "every shipped version": every schema state that ships has a committed snapshot, because CI refuses a migration without one.

## Consequences

The mapping from application version to schema version is derivable from the tag's journal.

## Evidence

- Plan 6.2 row PD-05.
- `G7.md` section 3: `pnpm schema:check` ran green locally. `apps/server/schema-snapshots/` and `schema-parity.test.ts` exist.
